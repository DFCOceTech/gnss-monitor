**Objective
*This project builds a GNSS monitor quality and to detect spoofing and jamming.

**Current hardware setup
*Raspberry Pi 4 4GB 
*Ublox ZED-X20P
*ANN-MB2 antenna

**Requirements
*Programming language is Python
*Record GNSS baseline in all bands and all constellations
*Detect changes in signal quality across bands
*Attribute changes to e.g. multi-path interference, spoofing, jamming
*Record GNSS data at 1Hz
*Write log file of quality metrics, assessments and attribution
*Display current status in a dashboard
*Create dashboard to look up previous interference/spoofing/jamming events and display them

**Out of Scope
*RF interference
*AIS spoofing
*ADS-B spoofing
